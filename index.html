De Artifice — the maker

Chapter one
of five

I start at the logic gate and keep going until there's a pixel someone can touch.

Based in Amman, I'm finishing a B.Sc. at Princess Sumaya University for Technology. Most engineers pick one layer of the stack. I like to own all of them: I've built a 5-stage RISC-V pipeline in Verilog, written CUDA image kernels, and run a QAOA solver against classical heuristics on 200-node routing problems.

Then I ship the product around it, and I break it on purpose. I'm a Performance Test Engineer at Q-Pros and a certified NeoLoad consultant, load-testing client systems with NeoLoad, JMeter, LoadRunner and ReadyAPI. I made the JADS web and mobile apps, which are live on the App Store and used by real members. I built an Azure government-services portal with no secrets in CI, and a native macOS PDF editor in Liquid Glass. Outside of code I help run Google I/O Extended, DevFest and Qiskit Fall Fest in Amman.
